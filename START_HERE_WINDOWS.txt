CRAZIFIEDEDITS V1.2.1 · BY CRAZIFIED STUDIOS
GOOGLE DRIVE + WEEKLY LOGS THROUGH 2030 + IPHONE-READY DESIGN

YOU ALREADY HAVE A SUPABASE ACCOUNT / SCHEMA:

1. Extract the CrazifiedEdits V1.2.1 ZIP into a NEW folder. Back up your old project.
   If V1.2 Google Drive is already configured, NO SQL MIGRATION is needed.
   Copy your previous .env.local and go straight to npm install / npm run dev.
2. In your existing Supabase project: SQL Editor -> New query -> paste
   sql/migrate_v1_2_google_drive.sql -> Run.
   Do NOT re-run sql/schema.sql or delete existing records.
3. Copy the old .env.local file into the new project folder. Keep your
   Supabase URL, API keys, ADMIN_EMAIL and existing secrets unchanged.
4. Open Google Cloud Console (console.cloud.google.com):
   - Enable Google Drive API.
   - Configure the Google Auth Platform consent screen.
   - Add your Gmail account as a Test user if status is Testing.
   - Create an OAuth client of type Web application.
   - Add redirect URI EXACTLY:
     http://localhost:3000/api/gdrive/callback
   - Copy the Google Client ID and Secret (DO NOT share them).
5. In .env.local ADD:
     GOOGLE_CLIENT_ID=<real-google-client-id>
     GOOGLE_CLIENT_SECRET=<real-google-client-secret>
     GOOGLE_REDIRECT_URI=http://localhost:3000/api/gdrive/callback
     GOOGLE_TOKEN_ENCRYPTION_KEY=<64 hex chars>
   Generate the encryption key via: node scripts/generate-secrets.mjs
   If you already have ONEDRIVE_ENCRYPTION_KEY, V1.2 can reuse it as a fallback.
   Old MICROSOFT_* settings are no longer used.
6. Open PowerShell IN the new V1.2 folder:
     npm install
     npm run dev
7. Open http://localhost:3000 - public client dashboard first.
8. Admin sign in at http://localhost:3000/login using your EXISTING
   Supabase email/password.
9. In admin, connect GOOGLE DRIVE. Copy your Google Drive FOLDER link
   (not a filename), paste under Folder to monitor, SAVE, click SYNC NOW.
10. Mark each synced reel Delivered after verifying its duration/date.
    Select week/year in the public dashboard. Every Monday-Sunday period
    through the end of 2030 exists even if no reels were logged that week.
11. On iPhone, open the hosted site. Use native Year/Week menus and
    mobile reel cards. The localhost URL only works on your PC unless
    you configure access to your local network.

NOTES:
- Preview: double-click preview.html for a fake-data design demo.
- Old OneDrive reel history is preserved, but Microsoft sync is removed.
- Google Drive does not automatically share files with Mohit.
- Google OAuth in External Testing can require reconnection after 7 days.
- Existing Supabase 'fetch failed' errors must be fixed independently.
- A commercial Vercel deployment requires a commercially permitted plan.
- Do NOT share keys or .env.local or publish credentials to GitHub.
